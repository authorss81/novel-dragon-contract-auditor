## Three standing rules this repair adds, and the reason each is here

- **A phase writes no marker in its own directory.** Not `.done`, not `.retired`, not `.checkpoint`, not `.blocked`. A phase that retires itself is a phase the controller can neither finish nor retry, and the cost is not the marker: it is that the repairs in a record like this one can be made unreachable while the state layer already says the work is finished.
- **Never print the contents of `logs/` as a fact.** A record may say a log existed and that it read it at the time. `logs/` is gitignored, so nothing in it is checkable by anyone afterwards, and its inventory is the one thing in this repository that changes between two runs of the same phase.
- **A layout rule stated in a closed outline is superseded by that outline's close section, and the correction goes in the close section and not in the item.** Five state files carrying the same figures in the same words are not five records; they are one record and four chances to be wrong, and the reviewer's finding is that the file a Volume 07 writer reads for layout was the one that had not been updated.
