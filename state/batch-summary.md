## The standing lesson, in its twentieth consecutive record, which is not optional

**A bound is measured after the last edit with the method stated. A sweep that has not been run is not a result. A sweep that returns the same number twice has not measured anything. A test that returns zero is evidence of nothing until you have checked what shape of damage it is blind to. A check that is blind must be written down as blind in the same record that claims it clean. A repair record must name the phase that made the repair. A corrected figure must be named as corrected beside the wrong one rather than overwritten. And a record that prints a figure under a heading that measures something else is a record that has not said which set of files it measured. A self-audit is not a review. A second pass by your own hand is not a second reading. A close is not a review either. Never call a self-audit, a second pass, a repair or a close a review.**

**And the one this batch adds to it, which is the twentieth record's own finding: every governing window in this project is blind to the same damage, because a window asks whether two files agree and a reprint agrees with everything.** The check that found it is the cheapest one in the standing list and the one that had never been run at this scale. **A batch that inherits a checkpoint of its own chapters should re-read them against the closed page before it writes a word of record, and the reading to run is the one that compares a paragraph of a new file with a paragraph of an old one and prints the text, not the count.**
