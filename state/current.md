## The standing lesson, in its twentieth consecutive record, which is not optional

**A bound is measured after the last edit with the method stated. A sweep that has not been run is not a result. A sweep that returns the same number twice has not measured anything. A test that returns zero is evidence of nothing until you have checked what shape of damage it is blind to. A check that is blind must be written down as blind in the same record that claims it clean. A repair record must name the phase that made the repair. A corrected figure must be named as corrected beside the wrong one rather than overwritten. A record that prints a figure under a heading that measures something else is a record that has not said which set of files it measured. A self-audit is not a review. A second pass by your own hand is not a second reading. A close is not a review either. Never call a self-audit, a second pass, a repair or a close a review: that is the failure this project has made four times, and a record that makes it makes a debt look discharged when it is not.** **And this batch's own addition, which is the one a next writer should act on: a phase that inherits a checkpoint containing its own chapters should read them against the closed page before it writes a word of record, and a checkpoint is a file and not a finding.**
